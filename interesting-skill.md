# Skill: interesting MCP Server

You have access to the **interesting** MCP server, which provides tools for
tracking news stories of interest.

## Available Tools

### `add_topic`
- **Parameters:**
  - `title` (string, required): Title of the topic. Must be ASCII, non-empty, max 128 characters.
  - `scope` (string, optional): Scope of the topic. Must be ASCII, max 32 characters. Defaults to `"world"`.
- **Returns:** JSON object `{"id": "...", "title": "...", "scope": "..."}` with the created topic, including its generated UUID.
- **Use when:** the user wants to start tracking a new topic of interest.

### `list_topics`
- **Parameters:** none
- **Returns:** JSON array of topic objects, each with `id`, `title`, and `scope`. Returns an empty array if no topics exist.
- **Use when:** the user wants to see all currently tracked topics.

### `remove_topic`
- **Parameters:**
  - `id` (string, required): The UUID of the topic to remove (case-sensitive).
- **Returns:** `"OK"` on success. Returns an error if the topic is not found.
- **Use when:** the user wants to stop tracking a topic.

## Usage Notes

- Topic IDs are UUIDs generated by the server when a topic is added. Store the
  `id` from `add_topic` if you need to remove the topic later.
- IDs are case-sensitive — use the exact value returned by `add_topic` or
  `list_topics`.
- The server may be running as a persistent streamable HTTP server (e.g., via
  `MCP_TRANSPORT=streamable-http python -m interesting.server --db topics.db`).
  In that case it retains state across sessions and is reachable at
  `http://localhost:8000/` by default.
